# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [hello@uptrack.app](mailto:hello@uptrack.app), with **Security report** in the subject. Include the affected version or commit, the platform and device where applicable, steps to reproduce, and the impact you observed. Please do not include passwords, access tokens, private user data, or other secrets in your report.

Do not disclose suspected vulnerabilities in public issues, discussions, or pull requests until Uptrack has had an opportunity to investigate and coordinate a fix. We will acknowledge reports and follow up as we learn more; please allow time for investigation before public disclosure.

## Scope

This policy covers security issues in the Uptrack Mobile repository, including the Flutter application, its iOS and Android code, and repository-hosted build and release workflows. Issues in other Uptrack services may also be reported to the address above; please identify the affected service in your report.

## Supported versions

Security fixes are made against the latest development version. When a supported app release is available, report its version and platform so we can assess affected releases.
